# CLAQE Development Rules

You are developing CLAQE, an AI filmmaking application.

- Keep explanations brief.
- Read only relevant files.
- Never rewrite working code unnecessarily.
- Do not print complete source files in chat.
- Make focused changes and test them.
- Avoid repetitive debugging attempts.
- Prefer Sonnet for regular coding.
- Use development branches, not main.
- Never expose secrets.
- Never deploy to production without approval.
- Ask before using paid APIs.
- Report results in 5 lines or fewer.
